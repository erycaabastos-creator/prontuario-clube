Importar anamneses antigas (Google Forms)

No Google Forms, abra a planilha de respostas, vá em Arquivo > Fazer download > Valores separados por vírgula (.csv), e envie o arquivo aqui. Cada linha vira uma anamnese. Se o atleta ainda não existir no sistema (pelo nome), ele é criado automaticamente. Atletas que já têm anamnese preenchida no sistema são pulados, para não sobrescrever nada.
